B232270105 - Б.Хан-Эрдэнэ

### Дүгнэлт

Энэ хичээлээр oлон тестийн сонголтуудаас аль аль нь зөв, зохистой тест болгож болгохыг сурлаа. Эхлээд тестийн сонголтууд, specification-г гаргаж, дараа нь restraint бичэн илүү нарийн болгосон. Энэ нарийвчлалыг яг тооцоолж мөн сурж, үнэлж сурав. 

Дараагийн ажлаар тестийн комбинаторикын асуудлыг PICT-р шийдвэрлэж сурсан. Энэ програм аль хоёр утга (эсвэл түүнээс дээш) ядаж нэг удаа цуг байх шийдвэрийг олгодог. Яагаад гэвэл аль хоёр утгын комбинацууд судалгаагаар 60-95%-н согогийг олдог хэмээн олдсон байдаг. 

Энэ аргуудийн үр дүнд бодит тестүүд үүсэж, бичих явдлийг хялбарчуулна. Тестийн үр дүнд програм хангамж аливаа шинэ функцид алдаа гаралгүй, тэсвэртэй хөжүүлэлт өрнөнө.
